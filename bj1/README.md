# 北京地铁 1号线 / 八通线 · DKZ4 驾驶模拟

纯前端 3D 驾驶模拟器，使用 **Three.js + 原生 HTML / CSS / JavaScript**。
线路、车辆、时刻表、ATP 曲线、交路与评分逻辑均硬编码于源码中，无后端、无外部数据请求。

> **Release 0.0.1**：首个可发布版本。纯静态、无后端、无 CDN，可直接部署到 GitHub Pages；DKZ4 模型已打包为根目录下的 `dkz4.glb`。

## 启动

### 线上（GitHub Pages）

仓库根目录即站点根目录，全部为相对路径，无需任何构建步骤：

- 关闭 Jekyll：可选，放一个空的 `.nojekyll` 可以避免 GitHub Pages 对下划线开头文件名的处理。
- Settings → Pages → Deploy from a branch → 选分支 + `/ (root)`。
- 部署后直接访问 `https://<user>.github.io/<repo>/` 即可。
- 模型地址与仓库内路径严格一致：`./dkz4.glb`（小写，位于仓库根目录）。

### 本地

```powershell
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

`file://` 双击打开时浏览器会拦截模型的 fetch 请求，模拟器仍可运行，但会回退到程序化车体；这不影响驾驶、信号与评分。

首次进入会看到「点击进入」遮罩：**必须单击一次**，音频引擎与语音合成才会在用户手势内初始化（HTTPS 下浏览器的自动播放策略要求如此）。

所有脚本、Three.js、GLTFLoader 与模型均已本地化，无 CDN、无后端。

推荐 Chrome / Edge，全屏 1440×900 或以上，开启声音。

## DKZ4 高精度模型

- 源文件：`dkz4.glb`（约 11.7 MB，GLB 容器，内嵌 4096² 贴图），位于仓库根目录。
- 加载器：本地 `vendor/GLTFLoader.js`，入口在 `index.html` 中位于 `three.min.js` 之后。
- 由原始 `dkz4_0.gltf` 转换而来，转换脚本为 `tools/gltf-to-glb.js`（`node tools/gltf-to-glb.js dkz4_0.gltf dkz4.glb`），不参与运行时。
- 模型原始结构包含 6265 个 Mesh / 约 15 万顶点，且同一位置叠有“头车”和“中间车”两套外观。`js/world.js` 按顶层组名把它们拆成 `head` / `middle` 两个变体，各自烘焙成一个 `BufferGeometry`；头车、尾车用头车变体，中间四节用中间车变体，每节车只产生 1 个 draw call。
- 自动按包围盒把长轴缩放到 `VEHICLE.carLength`（19 m），横向居中、底面落到轨面；模型长轴为 Z、车头朝 -Z，代码中旋转到车辆局部 +X，尾车再旋转 180°。
- 车头/车尾目的地牌在模型装配后动态挂载，仍随大小交路终点实时更新。
- 加载过程中底部显示进度；失败时控制台给出原因，并保留原程序化列车，不影响 ATP、车门、评分与交路逻辑。

## 已实现内容

### 线路与运营

- 古城 — 环球度假区，贯通运营线路 **54.47 km，35 站，全程 85 分钟**（时刻表精确标定 5100 秒）。
- 全部 35 个站名、英文名、站间里程、站台形式与换乘线路硬编码。
- 站间里程采用官方乘客站间距：古城—环球度假区合计 **48.294 km**（如南礼士路—复兴门 424 m）。54.47 km 保留为贯通运营线路长度口径。
- 工作日早高峰：大交路 古城↔环球度假区，小交路 **公主坟↔果园**，行车间隔 **1分45秒**。
- 工作日晚高峰：大交路 古城↔环球度假区，小交路 **古城↔果园**，行车间隔 **2分20秒**。
- 发车前选择时段、交路、方向、ATO/人工模式；列车目的地牌、终点站与交路随之更新。
- 小交路终点：关妥车门后 30 秒自动折返，也可手动点击“立即折返”或结束值乘。
- 前方虚拟列车按运行图提前一个行车间隔动态运行、停站、再起动。
- 后方列车按本车实际位置历史延迟一个行车间隔物理跟随，前后车距离常驻显示。
- 相邻轨道生成一列同型 DKZ4 对向列车，按相同时段行车间隔形成反向车流并与本车交会。

八角游乐园站因改造暂未列入当前官方站间距表，本模拟保留该站，采用 2014 年里程表的 1921 m，并由古城—八宝山合计 3874 m 推得八角游乐园—八宝山 1953 m。

### CBTC / ATP / ATO

- 连续移动闭塞速度曲线，不使用固定闭塞红绿灯。
- 根据下一站停车点与前车车尾距离实时计算：
  - ATP 允许速度；
  - 目标类型与目标距离；
  - 制动距离与追踪间隔。
- 超速 2 km/h 报警；持续超速或瞬间大幅超速触发 EB；追踪距离不足触发 EB。
- EB 后手柄/牵引完全锁闭，列车必须完全停稳，再按面板“复位”或 `R` 才能重新牵引。
- ATO 自动跟随最优曲线运行至下一站，司机只负责开关门与发车授权；人工模式下手柄操纵、ATP 后台监督。
- ATO 按运行图闭环控速：当检测到早点趋势时自动降低目标速度或惰行，**进站提前量不超过 5 秒**。

### DKZ4 车辆逻辑

- 3M3T / 6 节编组（Mc-T+M-T′+T-Mc），车长 19 m，车宽 2.8 m，车高 3.51 m。
- 设计最高 80 km/h，运营 70 km/h。
- 起动加速度 0.83 m/s²；常用制动 0.94 m/s²；紧急制动 1.19 m/s²。
- 牵引 4 段、常用制动 7 段、EB 独立按钮；手柄式主控制器。
- 功率限制、运行阻力、坡度重力分量、保持制动、门联锁均参与动力学计算。
- DC 750V 第三轨、上接触式集电靴、VVVF/GTO、1C4M 等信息已写入车辆数据。

### EB 保护逻辑

- 手动 ATP 模式下持续超出允许速度：先报警，超过阈值并持续约 0.9 秒后触发 EB。
- 无视前车距离、逼近移动闭塞曲线：ATP 提前报警并施加 EB。
- EB 触发后手柄被锁闭，正向牵引指令无效；列车按 1.19 m/s² 紧急制动直至完全停稳。
- 完全停稳后“复位”按钮生效；复位后方可重新推牵引。
- ATO 按图运行时同样受 ATP/EB 保护。

### 车门、停车与评分

- 列车停稳且处于站台区域才能开门。
- 开门后牵引被封锁；关妥车门后才能发车。
- 停车误差：
  - ≤ ±0.5 m：停车精准；
  - 0.5–1.0 m：停车不准；
  - > 1.0 m：冲标 / 欠标。
- 评分维度：停车精度 40%、安全运行 30%、准点率 20%、操作规范 10%。
- 统计 EB 次数、超速时间、漏停、车门联锁违规、发车偏差、最高速度与平均停车误差。

### 列车追踪与对向列车

- 前车：按运行图提前一个行车间隔运行，参与 ATP 移动闭塞曲线与 EB 防护。
- 后车：按本车位置历史延迟一个行车间隔跟随，并限制不得越过本车车尾，提供后车距离/速度。
- HUD 常驻显示前车、后车距离与速度。
- 按 `Tab` 或点击顶部 `⇄` 打开 2D 追踪图：当前站区间、本列绿点、前车红点、后车黄点及距离。
- 对向列车：相邻轨道生成同型 DKZ4，按同一行车间隔形成反向车流，动态交会。

### 动态报站

- 使用浏览器 `window.speechSynthesis`，无外部音频文件。
- 发车后自动播报下一站；到站自动播报“XX站到了”。
- 换乘站自动播报可换乘线路：复兴门/建国门 2号线、西单 4号线、东单 5号线、国贸 10号线、公主坟 10号线、军事博物馆 9号线、木樨地 16号线、王府井 8号线、大望路 14号线、花庄/环球度假区 7号线。
- 中文与英文分句播报；`M` 静音会同时关闭报站。

### 3D 场景

- 第一人称驾驶室（含操纵台、手柄、车门按钮、雨刷、DMI 屏）与 DKZ4 外观视角（`V`）。
- 外观视角是绕**车头**轴心的球面轨道机位：拖动旋转（可绕到车头正前方）、滚轮缩放，双击或 `Shift`+`R` 回默认机位。
- 机位始终被夹在线路断面内：地下区间不会穿出 ±10.1 m 的侧墙和 6.08 m 的顶板，高架区间不会钻到桥面以下；撞墙时优先缩短距离、保持观察角度。
- 临时调试：外观视角下 `Shift`+滚轮 可微调车头顶部终点站牌的前后偏移（每格 2 cm），屏幕底部实时显示 `offset`，取到合适值后该功能会被移除。
- 外观车辆优先使用仓库根目录的 `dkz4.glb`（`./dkz4.glb`）高精度模型；加载失败或 `file://` 受限时无缝回退到原程序化 DKZ4。
- 古城—四惠东地下隧道；四惠东—土桥高架/地面；花庄—环球度假区地下/半地下。
- 岛式、侧式、四惠东一岛两侧式站台；屏蔽门/半高安全门、黄色安全线、导向标识。
- 西端 **古城、八角游乐园为侧式站台**（轨道居中、两侧各一座站台），地下站厅向两侧加宽到 25.6 m，区间隧道墙在站台范围断开、由站体端墙收口；苹果园站位于古城以西，不在本模拟 54.47 km 线路范围内。
- 侧式站台站牌分别悬挂在两侧站台雨棚下，不再跨越轨道；岛式站牌悬挂于站台中心。
- **花庄站南侧上下行左右互换**：两条正线在 168 m 内以 X 形交叉曲线换到对侧，交叉后一直保持互换至环球度假区；这是纯视觉改造，列车仍按主逻辑沿 ±5.5 m 轨道中线直行。
- **静态配线（纯装饰，见下）**：玉泉路联络线、古城车辆段、公主坟站后折返线、环球度假区掉头线、土桥车辆段出入段线，以及复兴门/东单的交叉渡线与 2 号线、北京站方向联络线、四惠两端单渡线、四惠东贯通 4 组道岔、八角游乐园 101 线预留线；全部用 `THREE.CatmullRomCurve3` 生成钢轨/道床/轨枕，接点处与主线相切，交叉处抬高 5 mm 防闪烁，不参与碰撞、限速与 ATO。
- 高架两侧设置灰色半透明隔音屏与立柱，在站台范围自动留出开口。
- 双侧轨道、轨枕、钢轨、第三轨及防护罩、电缆槽、疏散平台。
- 地下人工照明与列车头灯；高架段天空光、方向性阳光与阴影、沿线条形城市与跨线桥。
- 站名牌、停车标、CBTC 标牌、限速标、公里标方向的轨旁设施。

| 八角游乐园 101 线预留线 | 八角游乐园站东 232–330 m | 一号线支线（101 线）预留分支，向南侧下坡，洞门开在侧壁 |

细节处理：

- 曲线两端用 smoothstep 过渡，横向与竖向斜率均为 0，因此与正线、与相邻配线在接点处**严格相切**，不会出现折角。
- 所有交叉/汇合处的一条轨道整体抬高 **5 mm**（`YARD.crossBias`），避免共面闪烁；配线轨枕比正线轨枕高 7 mm，避免叠面。
- 钢轨、道床、轨枕随曲线逐点采样（普通段 3 m、咽喉段更密），轨枕按线路切线自动旋转。
- **道岔咽喉与菱形交叉换用加长枕木**：咽喉段两端各 ~9 m 用 3.35 m 加长枕木，X 形交叉中心额外铺 3 根横向加长枕木。
- 高架下的出入段线附带混凝土桥面与桥墩，地下洞室附带端墙、照明与点光源；联络线在隧道侧壁上有带门框的黑色洞门。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `↑` | 牵引 +1 段（P1–P4） |
| `S` / `↓` | 制动 +1 段（B1–B7） |
| `X` | 手柄回零 |
| `O` | 开门 / 关门 |
| `Space` | ATO 发车授权 |
| `E` | 紧急制动 EB |
| `R` | 停稳后复位 EB |
| `H` | 鸣笛 |
| `V` | 驾驶室 / DKZ4 外观视角 |
| `T` | ATO / ATP 人工模式切换 |
| `Tab` | 打开 / 关闭 2D 列车追踪图 |
| `M` | 静音（含报站语音） |
| `P` / `Esc` | 暂停 |
| `[` / `]` | 降低 / 提高模拟倍率 |
| 鼠标拖动 | 驾驶室内环视；外观视角绕车头旋转 |
| 滚轮 / `+` `-` / `PgUp` `PgDn` | 外观视角拉近 / 推远（0.3×–4.2×） |
| `Shift`+滚轮（外观视角，临时） | 车顶终点站牌前后微调 2 cm/格，底部显示 `offset` |
| 双击 / `Shift`+`R` | 回正视线；外观视角同时回到默认机位 |

ATO 模式下：停稳 → `O` 开门 → 再按 `O` 关门 → `Space` 发车。
人工模式下：停稳 → `O` 开门 → 再按 `O` 关门 → `W` 推牵引。
注意中央提示中的计划发车时刻；早发车同样会拉低准点率。

## 版本与发布

- 当前版本 **Release 0.0.1**，版本号同时出现在进入页徽标、开始页底部与 `package.json`。
- 发布方式：仓库根目录直接作为 GitHub Pages 站点根目录，纯静态、无构建、无后端、无 CDN；模型、贴图、脚本、样式全部走相对路径。
- 进入页遮罩不是装饰：浏览器（尤其 HTTPS 下的 Chrome/Safari）要求音频与语音合成必须在用户手势后启动，因此 `AudioContext` 与 `speechSynthesis` 都在「点击进入」之后才创建。
- 模型为单文件 11.7 MB，GitHub Pages 单文件上限 100 MB，可直接托管；首次加载会有一点等待，页面底部有进度提示。
- 需要本地转换模型时：`node tools/gltf-to-glb.js dkz4_0.gltf dkz4.glb`。

## 简化说明

- 城市与车辆为低多边形风格化模型，重点保证线路结构与驾驶逻辑。
- 终端折返仍采用站内换端简化；公主坟折返线、环球掉头线与各处渡线只是静态装饰，不参与进路排列。
- 同向分别模拟一列前车与一列后车；对向车流按行车间隔生成，但场景内只渲染离本车最近的一列，控制性能。
- 后车采用本车实际位置历史延迟一个行车间隔跟随，不单独模拟其车门与停站。
- 报站依赖操作系统/浏览器提供的语音合成音色；没有中文语音包时会使用浏览器默认发音。
- 客流仅以车门开关和停站时间体现，不模拟个体乘客。
